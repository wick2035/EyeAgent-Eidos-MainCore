### 2. 报告数据服务 ✅

**文件**: `database/report_service.py`

**核心功能**:
- 生成唯一报告编号（FILE-{year}-{sequence}格式）
- 查询病例完整信息（包含新增字段）
- 获取用户所有历史报告
- 获取用于填充模板的格式化数据
- 更新报告相关字段
- 分配报告编号并标记打印时间

**关键方法**:
- `get_medical_record_full()` - 获取完整病例信息
- `get_all_reports_by_patient()` - 获取用户所有报告
- `get_report_data_for_template()` - 获取模板数据
- `assign_report_id()` - 分配报告编号
- `update_report_fields()` - 更新报告字段
- `get_records_for_analysis()` - 获取用于分析的记录

### 3. 报告生成工具 ✅

**文件**: `utils/report_generator.py`

**核心功能**:
- 读取并填充docx模板
- 自动替换模板中的占位符
- 转换docx为PDF（支持docx2pdf和pypandoc）
- 如果模板不存在，自动创建新文档
- 支持批量生成报告

**关键方法**:
- `generate_report_from_db()` - 从数据库生成报告
- `generate_report_from_data()` - 从数据字典生成报告
- `batch_generate()` - 批量生成报告

**依赖包**:
```
python-docx==1.1.0
docx2pdf==0.1.8  # Windows
pypandoc==1.12   # 跨平台
```

### 4. 报告智能体 ✅

**文件**: `agents/agent_2.py`

**核心功能**:
- 对话式报告生成
- 病情趋势分析
- 多次就诊记录对比
- 异常检测
- 历史病例问答

**对话阶段**:
- `GREETING` - 问候
- `SELECT_ACTION` - 选择操作
- `GENERATE_REPORT` - 生成报告
- `ANALYZE_HISTORY` - 分析历史
- `ANSWER_QUESTION` - 回答问题
- `COMPARE_RECORDS` - 对比记录
- `COMPLETED` - 完成

**关键方法**:
- `generate_report()` - 生成报告
- `analyze_history_trends()` - 趋势分析
- `compare_records()` - 对比记录
- `detect_anomalies()` - 异常检测
- `answer_history_question()` - 回答问题

### 5. API接口集成 ✅

**文件**: `main.py`

**新增接口**:

#### POST /api/report/generate
生成病例报告PDF
```json
{
  "patient_id": 1,

}
```

#### GET /api/report/history/{patient_id}
获取历史报告列表

分析历史报告
```json
{
  "patient_id": 1,
  "analysis_type": "trends"  // trends | compare | anomalies
}
```

#### POST /api/chat/report
报告智能体对话接口（类似 /api/chat）

## 使用示例

### 1. API方式

#### 生成报告
```bash
curl -X POST http://localhost:8000/api/report/generate \
  -H "Content-Type: application/json" \
  -d '{"patient_id": 1}'
```

#### 分析趋势
```bash
curl -X POST http://localhost:8000/api/report/analyze \
  -H "Content-Type: application/json" \
  -d '{"patient_id": 1, "analysis_type": "trends"}'
```

#### 对话
```bash
curl -X POST http://localhost:8000/api/chat/report \
  -H "Content-Type: application/json" \
  -d '{"message": "生成最新报告", "patient_id": 1}'
```

### 2. 代码方式

```python
from agents.agent_2 import ReportAgent
from utils.report_generator import ReportGenerator

# 使用智能体
agent = ReportAgent(patient_id=1)
response, _ = agent.chat("生成最新的病例报告")

# 直接生成报告
generator = ReportGenerator()
pdf_path = generator.generate_report_from_db(medical_record_id=1)
```

## 注意事项

### 1. 数据库迁移
**重要**: 现有数据库必须执行迁移脚本添加新字段

```powershell
# Windows PowerShell
Get-Content database\migrations\add_report_fields_simple.sql | mysql -u root -p20041118

# Linux/Mac
mysql -u root -p20041118 < database/migrations/add_report_fields_simple.sql
```

### 2. PDF转换
- Windows优先使用 `docx2pdf`
- 其他平台使用 `pypandoc`
- 如果都失败，生成docx文件（可手动转换）

### 3. 编码问题
- Windows控制台可能不支持emoji字符显示
- 不影响实际功能，仅影响日志输出

### 4. 模板文件
- 默认使用 `example/bingli.docx`
- 如果不存在会自动创建新文档
