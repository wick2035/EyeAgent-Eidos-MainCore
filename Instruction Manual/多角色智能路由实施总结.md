## 🎯 功能特性

### 智能Agent路由
系统会根据对话内容自动选择合适的Agent：

| 用户输入 | 检测到的Agent | 说明 |
|---------|-------------|------|
| "我眼睛疼" | HealthAgent | 症状咨询 |
| "查看历史报告" | ReportAgent | 报告查询 |
| "我想预约医生" | HealthAgent | 预约服务 |
| "对比两次记录" | ReportAgent | 数据分析 |

### 角色权限矩阵

| 功能 | 患者 | 医生 |
|-----|------|------|
| 健康咨询 | ✅ | ✅ |
| 症状评估 | ✅ | ✅ |
| 医生预约 | ✅ | ✅ |
| 查看历史报告 | ✅ | ✅ |
| 分析病情趋势 | ✅ | ✅ |
| 对比历史记录 | ✅ | ✅ |
| **生成病例报告** | ❌ | ✅ |

### 三层权限控制

1. **意图识别层**（最早拦截）
   - 检测到患者尝试生成报告
   - 直接返回blocked标志
   - 不会调用ReportAgent

2. **Agent层**（核心验证）
   - 在generate_report()方法中检查
   - 拒绝患者的生成请求
   - 返回友好提示

3. **提示词层**（AI理解）
   - 在对话模板中说明权限
   - 让AI自然地处理权限问题

## 🔧 技术实现

### 意图识别算法
1. **快速关键词匹配**（响应快）
   - 健康关键词：症状、疼痛、预约等
   - 报告关键词：报告、历史、分析等

2. **规则判断**（准确率高）
   - 明确触发词直接路由
   - 权限预检查

3. **LLM辅助**（处理模糊情况）
   - 当关键词不明确时调用
   - 使用对话历史增强判断

### Agent切换机制
```python
# 检测到需要切换
if current_agent != detected_agent:
    agent_manager.reset_agent(session_id)  # 重置旧Agent
    agent = agent_manager.get_or_create_agent(
        session_id, 
        detected_agent, 
        role=role
    )  # 创建新Agent
```
