# Agent3 新增和取消提醒功能使用指南

## 功能概述

Agent3 现已完全支持以下功能：

### ✅ 新增提醒功能
- **创建复诊提醒** - 自动提醒患者复诊日期
- **创建预约提醒** - 自动提醒患者预约就诊时间
- **创建用药提醒** - 自动提醒患者按时用药

### ✅ 取消提醒功能
- **取消指定提醒** - 通过ID取消提醒
- **智能提示** - 无需记忆ID，系统会列出可取消的提醒

---

## 使用方法

### 1. 创建复诊提醒

**对话流程：**
```
用户: 创建复诊提醒
Agent: 好的，我来帮您创建复诊提醒。请告诉我复诊日期（例如：2025-12-01 或 明天/后天）

用户: 2025-12-15
Agent: 好的，复诊日期设为：2025年12月15日。请问需要提前几天提醒您？（直接输入数字，默认3天）

用户: 3
Agent: ✅ 复诊提醒创建成功！
      📅 复诊日期：2025年12月15日
      ⏰ 提前提醒：3天
      我会在 2025年12月12日 提醒您。
```

**支持的日期格式：**
- 标准格式：`2025-12-01`, `2025/12/01`
- 简化格式：`12-25`, `12月25日`
- 相对日期：`明天`, `后天`, `下周`

---

### 2. 创建预约提醒

**对话流程：**
```
用户: 创建预约提醒
Agent: 好的，我来帮您创建预约提醒。请告诉我预约时间（例如：2025-12-01 14:00 或 明天下午2点）

用户: 明天下午2点
Agent: 好的，预约时间设为：2025年11月18日 14:00。请问需要提前几天提醒您？（直接输入数字，默认1天）

用户: 1
Agent: ✅ 预约提醒创建成功！
      📅 预约时间：2025年11月18日 14:00
      ⏰ 提前提醒：1天
      我会在 2025年11月17日 提醒您。
```

**支持的时间格式：**
- 完整格式：`2025-12-01 14:00`
- 自然语言：`明天下午2点`, `今天14:30`
- 时间点：`14:00`, `下午3点`

---

### 3. 创建用药提醒

**对话流程：**
```
用户: 创建用药提醒
Agent: 好的，我来帮您创建用药提醒。请告诉我药物名称：

用户: 玻璃酸钠滴眼液
Agent: 药物名称：玻璃酸钠滴眼液。请告诉我用法用量（例如：每日3次，每次1-2滴）：

用户: 每日3次，每次1-2滴
Agent: 用法用量：每日3次，每次1-2滴。请告诉我疗程天数（例如：7）：

用户: 7
Agent: ✅ 用药提醒创建成功！
      💊 药物：玻璃酸钠滴眼液
      📋 用法：每日3次，每次1-2滴
      📅 疗程：7天
      ⏰ 提醒频率：每日
      从明天开始，我会每天提醒您按时用药。
```

---

### 4. 查看提醒列表

**命令：**
```
查看提醒          # 查看所有提醒
查看待处理提醒     # 只查看待处理的提醒
我的提醒          # 查看所有提醒
```

**示例输出：**
```
📋 您的提醒列表

⏰ 待处理 (2条)
🏥 复诊提醒 - 2025-12-15 09:00:00 (ID:1)
💊 用药提醒 - 2025-11-18 09:00:00 (ID:2)

您可以：
- 查看详情：「查看提醒 ID:X」
- 取消提醒：「取消提醒 ID:X」
- 完成提醒：「完成提醒 ID:X」
```

---

### 5. 取消提醒

**方式一：直接指定ID**
```
用户: 取消提醒 ID:1
Agent: ✅ 提醒已成功取消（ID:1）
```

**方式二：不记得ID时**
```
用户: 取消提醒
Agent: 📋 待处理的提醒 (可取消)

      🏥 复诊提醒 - 2025-12-15 09:00:00 (ID:1)
      💊 用药提醒 - 2025-11-18 09:00:00 (ID:2)

      请回复：「取消提醒 ID:X」来取消指定的提醒

用户: 取消提醒 ID:1
Agent: ✅ 提醒已成功取消（ID:1）
```

---

### 6. 中途取消创建

在创建提醒的过程中，可以随时取消：
```
用户: 创建复诊提醒
Agent: 好的，我来帮您创建复诊提醒。请告诉我复诊日期...

用户: 取消
Agent: 好的，已取消创建提醒。还有什么我可以帮您的吗？
```

**取消关键词：** `取消`, `不了`, `算了`

## 代码示例

### Python 调用示例

```python
from agents.agent_3 import ReminderAgent

# 初始化Agent
agent = ReminderAgent(patient_id=1, role="patient")

# 创建复诊提醒
agent.chat("创建复诊提醒")
agent.chat("2025-12-15")
response, _ = agent.chat("3")
print(response)  # 输出：复诊提醒创建成功！

# 查看提醒
response, _ = agent.chat("查看提醒")
print(response)  # 输出：提醒列表

# 取消提醒
response, _ = agent.chat("取消提醒 ID:1")
print(response)  # 输出：提醒已成功取消
```

### 使用手机号初始化

```python
# 推荐使用手机号（支持多条病历记录）
agent = ReminderAgent(phone_number="13900000001", role="patient")
```

## 技术实现细节

### 新增功能
1. **状态管理**：使用 `CREATE_REMINDER` 阶段和多步骤流程
2. **日期解析**：支持多种日期格式和自然语言
3. **数据验证**：自动验证用户输入的有效性
4. **数据库操作**：调用 `ReminderService` 创建提醒记录

### 取消功能
1. **ID提取**：正则表达式提取提醒ID
2. **智能提示**：无ID时显示可取消的提醒列表
3. **状态更新**：更新提醒状态为 `cancelled`
4. **历史记录**：记录取消操作到 `reminder_history` 表

### 日期解析支持
- **相对日期**：今天、明天、后天、下周、下月
- **标准格式**：ISO格式、中文格式
- **时间点**：支持小时分钟解析
- **智能补全**：自动补充年份

## 数据库结构

### reminder 表
```sql
- Reminder_ID: 提醒ID（主键）
- Patient_ID: 患者ID
- Reminder_Type: 提醒类型（follow_up/appointment/medication）
- Reminder_Title: 提醒标题
- Reminder_Content: 提醒内容
- Scheduled_Time: 计划提醒时间
- Advance_Days: 提前提醒天数
- Status: 状态（pending/sent/completed/cancelled）
- Priority: 优先级（low/normal/high/urgent）
- Repeat_Type: 重复类型（once/daily/weekly/monthly）
```

### reminder_history 表
```sql
- History_ID: 历史记录ID
- Reminder_ID: 关联的提醒ID
- Action_Type: 操作类型（created/sent/completed/cancelled）
- Action_Time: 操作时间
- Action_By: 操作人
```

## 注意事项

1. **编码问题**：在Windows GBK环境下打印emoji可能出现编码错误，这不影响功能本身
2. **权限控制**：创建提醒时会记录创建者角色（patient/doctor）
3. **数据持久化**：所有提醒数据存储在MySQL数据库中
4. **重复提醒**：用药提醒支持每日重复，其他提醒默认为一次性
5. **提醒时间**：系统会根据 `Scheduled_Time` 和 `Advance_Days` 计算实际提醒时间
