## ❌ 常见问题排查

### 问题: 测试脚本显示"无法连接到服务器"

**解决**:
```bash
# 检查服务器是否运行
# 在浏览器打开 http://127.0.0.1:8000
# 应该看到聊天界面

# 如果没有运行，启动服务器
python main.py
```

### 问题: 对话完成但没有保存到数据库

**检查服务器日志**:
- 查找 `[调试] 对话完成状态: True, 需要预约: False`
- 如果 `needs_appointment` 为 False，说明智能体认为不需要预约

**解决**: 在对话中明确表示需要预约，使用关键词：
- "我想预约"
- "需要预约"
- "是的，预约医生"
- "好的，预约"

### 问题: 数据库连接失败

**检查**:
```bash
# 测试数据库连接
mysql -u root -p20041118 -e "SELECT 1;"

# 如果失败，检查：
# 1. MySQL 是否已启动
# 2. 密码是否正确（在 database/db_config.py 中）
# 3. 数据库 medical_db 是否存在
```

### 问题: 找不到可用医生

**检查医生数据**:
```sql
SELECT 
    Doctor_ID, 
    Name, 
    Title, 
    Specialty, 
    Available_Time 
FROM doctor;
```

**确保**:
- 有医生记录
- `Available_Time` 字段格式正确：`2025-11-15, 09:00-11:00, 是`
- 日期是未来的日期

**修复示例**:
```sql
-- 更新医生的空闲时间
UPDATE doctor 
SET Available_Time = '2025-11-15, 09:00-11:00, 是' 
WHERE Doctor_ID = 1;

UPDATE doctor 
SET Available_Time = '2025-11-15, 14:00-16:00, 是' 
WHERE Doctor_ID = 2;
```

## 🔧 手动验证数据库

如果想手动检查数据库内容：

```sql
-- 查看最新的患者记录
SELECT 
    Patient_ID,
    Visit_Card_Number,
    Name,
    Age,
    Gender,
    Phone_Number,
    Chief_Complaint,
    Visit_Date
FROM patient
ORDER BY Patient_ID DESC
LIMIT 5;

-- 查看最新的预约记录
SELECT 
    a.Appointment_ID,
    a.Patient_Name,
    a.Appointment_Time,
    a.Appointment_Status,
    d.Name as Doctor_Name,
    d.Title as Doctor_Title
FROM appointment a
LEFT JOIN doctor d ON a.Doctor_ID = d.Doctor_ID
ORDER BY a.Appointment_ID DESC
LIMIT 5;
```
