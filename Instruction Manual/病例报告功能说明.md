# 病例报告功能使用说明

## 功能概述

第二个智能体（ReportAgent）专门用于病例报告生成和历史分析，提供以下核心功能：

1. **生成病例报告PDF** - 根据病例记录生成专业的病例报告文档
2. **病情趋势分析** - 分析用户历史病例，总结病情发展趋势
3. **对比就诊记录** - 对比多次就诊记录，发现变化和异常
4. **回答历史问题** - 回答用户关于历史病例的各种问题
5. **异常检测** - 检测历史记录中的异常变化

## 数据库变更

### 新增字段（medical_record 表）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| Report_ID | VARCHAR(50) | 报告编号（格式：FILE-{year}-{sequence}）|
| Visit_Time | DATETIME | 就诊时间（精确到时分）|
| Special_Exams | TEXT | 专项检查项目 |
| Auxiliary_Exams | TEXT | 辅助检查项目 |
| AI_Diagnosis | TEXT | AI自动诊断结果 |
| Doctor_Signature | VARCHAR(100) | 主诊医生签名 |
| Print_Time | TIMESTAMP | 病例单打印时间 |

### 数据库迁移

如果是现有数据库，请执行迁移脚本：

```bash
mysql -u root -p20041118 < database/migrations/add_report_fields.sql
```

如果是新建数据库，直接使用更新后的初始化脚本：

```bash
mysql -u root -p20041118 < database/init_database_v2.sql
```

## 使用方式

### 1. 通过API调用

#### 1.1 生成病例报告

```python
import requests

# 生成最新的病例报告
response = requests.post('http://localhost:8000/api/report/generate', json={
    "patient_id": 1
})

result = response.json()
print(f"报告路径: {result['file_path']}")

# 生成指定病例的报告
response = requests.post('http://localhost:8000/api/report/generate', json={
    "patient_id": 1,
    "medical_record_id": 2
})
```

#### 1.2 获取历史报告列表

```python
response = requests.get('http://localhost:8000/api/report/history/1')
reports = response.json()['reports']

for report in reports:
    print(f"病例ID: {report['Medical_Record_ID']}, 日期: {report['Visit_Date']}")
```

#### 1.3 分析历史报告

```python
# 趋势分析
response = requests.post('http://localhost:8000/api/report/analyze', json={
    "patient_id": 1,
    "analysis_type": "trends"
})
print(response.json()['result'])

# 异常检测
response = requests.post('http://localhost:8000/api/report/analyze', json={
    "patient_id": 1,
    "analysis_type": "anomalies"
})

# 对比分析
response = requests.post('http://localhost:8000/api/report/analyze', json={
    "patient_id": 1,
    "analysis_type": "compare",
    "record_ids": [1, 2, 3]
})
```

## API接口文档

### POST /api/report/generate

生成病例报告PDF

**请求体:**
```json
{
  "patient_id": 1,
  "medical_record_id": 2  // 可选，不提供则生成最新的
}
```

**响应:**
```json
{
  "success": true,
  "message": "报告生成成功",
  "file_path": "example/reports/report_1_FILE-2025-00001.pdf",
  "medical_record_id": 2
}
```

### GET /api/report/history/{patient_id}

获取历史报告列表

**响应:**
```json
{
  "success": true,
  "patient_id": 1,
  "count": 3,
  "reports": [
    {
      "Medical_Record_ID": 2,
      "Visit_Date": "2025-11-15",
      "Chief_Complaint": "视力模糊",
      "Diagnosis": "待诊断",
      "Report_ID": "FILE-2025-00001"
    }
  ]
}
```

### POST /api/report/analyze

分析历史报告

**请求体:**
```json
{
  "patient_id": 1,
  "analysis_type": "trends",  // trends | compare | anomalies
  "record_ids": [1, 2]  // compare类型时必需
}
```

**响应:**
```json
{
  "success": true,
  "analysis_type": "trends",
  "result": "分析结果文本..."
}
```

### POST /api/chat/report

报告智能体对话

**请求体:**
```json
{
  "message": "我想生成最新的病例报告",
  "session_id": "session-123",
  "patient_id": 1
}
```

**响应:**
```json
{
  "response": "好的，我将为您生成最新的病例报告...",
  "session_id": "session-123",
  "is_completed": false,
  "stage": "generate_report"
}
```

## 注意事项

1. **数据兼容性**: 新增字段全部可空，不影响现有数据和Agent1的预约功能
2. **报告编号**: 自动生成，格式为 `FILE-{year}-{sequence}`
3. **PDF转换**: 优先使用 docx2pdf（Windows），失败则使用 pypandoc
4. **文件存储**: 生成的PDF保存在 `example/reports/` 目录
5. **权限控制**: 确保只能访问自己的病例报告

## 与 Agent1 的关系

- **Agent1 (HealthAgent)**: 负责健康咨询、症状评估、医生预约
- **Agent2 (ReportAgent)**: 负责病例报告生成和历史分析

两个智能体相互独立，通过 AgentManager 统一管理：

```python
# 创建 Agent1
agent1 = agent_manager.create_agent("session1", "health", patient_id=1)

# 创建 Agent2
agent2 = agent_manager.create_agent("session2", "report", patient_id=1)
```

## 故障排除

### 问题1: 数据库字段不存在

**解决方案**: 执行迁移脚本
```bash
mysql -u root -p < database/migrations/add_report_fields.sql
```

### 问题2: PDF转换失败

**解决方案**: 
1. Windows环境安装 docx2pdf: `pip install docx2pdf`
2. 其他环境安装 pypandoc: `pip install pypandoc`
3. 如果都失败，会生成 docx 文件，可手动转换为 PDF

### 问题3: 找不到模板文件

**解决方案**: 
- 确保 `example/bingli.docx` 文件存在
- 如果不存在，系统会自动创建新文档

### 问题4: 报告生成路径错误

**解决方案**: 
- 确保 `example/reports/` 目录存在
- 系统会自动创建该目录
