# 多次预约功能修复说明

## 修复日期
2025-11-16

## 问题描述
之前的系统存在以下逻辑错误：
1. 没有明确区分历史预约（今天之前）和当前/未来预约（今天及以后）
2. 用户历史信息加载时，会显示所有预约，包括未来的预约
3. 对于是否支持同一患者多次预约不够明确

## 修复内容

### 1. 数据库服务层修改 (`database/user_history_service.py`)

#### 新增方法

**`get_historical_appointments(user_id, limit=10)`**
- 功能：查询用户的历史预约记录（今天之前的预约）
- SQL条件：`DATE(a.Appointment_Time) < CURDATE()`
- 返回：历史预约记录列表

**`get_current_future_appointments(user_id, limit=10)`**
- 功能：查询用户的当前和未来预约记录（今天及以后的预约）
- SQL条件：`DATE(a.Appointment_Time) >= CURDATE()`
- 返回：当前和未来预约记录列表

#### 修改的方法

**`get_user_complete_info(user_id)`**
- 现在返回三类预约信息：
  - `historical_appointments`：历史预约（今天之前）
  - `current_future_appointments`：当前/未来预约（今天及以后）
  - `has_history`：是否有历史数据（基于历史预约判断）

**`format_user_history_text(user_id)`**
- 分别显示历史预约和当前/未来预约
- 历史预约标注为"（今天之前的预约）"
- 当前/未来预约标注为"（今天及以后的预约）"

### 2. 智能体提示词修改 (`agents/agent_1.py`)

在AI助手的提示词中添加了以下说明：
```
- 【多次预约支持】患者可以预约多个医生，每次对话可以创建新的预约
- 历史信息中的"历史预约记录"仅包含今天之前的预约，今天及以后的预约不会显示在历史信息中
- 如果患者已有今天之后的预约，但想预约不同的医生或时间，可以创建新的预约记录
```

### 3. 预约服务确认 (`database/appointment_service.py`)

确认了现有逻辑已经支持同一患者多次预约：
- `create_patient()` 方法在患者已存在时返回现有患者ID
- `process_appointment()` 方法每次都会创建新的预约记录
- 没有任何限制阻止同一患者预约多个医生

## 数据库表结构支持

**appointment 表**结构天然支持多次预约：
```sql
CREATE TABLE appointment (
    Appointment_ID INT PRIMARY KEY AUTO_INCREMENT,  -- 每次预约生成唯一ID
    Patient_ID INT NOT NULL,                        -- 允许同一患者多次预约
    Doctor_ID INT NOT NULL,                         -- 可以预约不同医生
    Appointment_Time DATETIME,                      -- 每次预约的时间
    ...
);
```

关键点：
- `Appointment_ID` 作为主键，每次预约自动生成唯一ID
- `Patient_ID` 不是主键，同一患者可以有多条记录
- 没有唯一性约束限制一个患者只能有一个预约

## 使用示例

### 场景1：老用户再次预约新医生

```python
from agents.agent_1 import HealthAgent

# 创建智能体，传入用户ID
agent = HealthAgent(user_id=1)

# 用户对话
response = agent.chat("我想预约眼科医生")
# AI会加载历史信息，但只显示历史预约（今天之前的）
# 如果用户已有今天之后的预约，不会阻止创建新预约

response = agent.chat("我想预约明天的张医生")
# 系统会创建新的预约记录，即使该患者已有其他预约
```

### 场景2：查询用户的预约情况

```python
from database.user_history_service import UserHistoryService

service = UserHistoryService()

# 查询历史预约（今天之前）

# 查询当前和未来预约（今天及以后）

```

## 注意事项

1. **时间判断基于日期**：使用 `CURDATE()` 进行日期比较，不考虑具体时间
   - 今天00:00的预约属于当前预约
   - 昨天23:59的预约属于历史预约

2. **历史信息加载**：
   - AI助手首次对话时加载历史信息
   - 历史预约只包含今天之前的记录
   - 当前/未来预约会单独显示，但不作为"历史信息"

3. **预约逻辑**：
   - 患者可以预约多个不同的医生
   - 患者可以预约多个不同的时间段
   - 每次预约都是独立的记录

4. **数据完整性**：
   - 通过 `Patient_ID` 外键关联患者信息
   - 通过 `Doctor_ID` 外键关联医生信息
   - 删除患者时，相关预约会级联删除（ON DELETE CASCADE）
