# 数据库操作模块使用指南

## 概述

已为您创建了一个独立的数据库操作模块（`database/` 文件夹），该模块可以：

✅ **自动处理一号智能体的预约 JSON 输出**  
✅ **创建/更新患者病例**  
✅ **检查医生空闲时间**  
✅ **完成预约操作**

## 快速开始（3 步）

### 1️⃣ 安装依赖

```bash
pip install pymysql
```

### 2️⃣ 初始化数据库

```bash
mysql -u root -p20041118 < database/init_database.sql
```

这将创建：
- `medical_db` 数据库
- `doctor`、`patient`、`appointment` 三个表
- 5 条测试医生数据

### 3️⃣ 使用模块

```python
from database.appointment_service import AppointmentService
from agents.agent_1 import HealthAgent

# 从一号智能体获取患者数据
agent = HealthAgent()
# ... 完成对话流程 ...
patient_data = agent.get_patient_data()

# 使用数据库模块处理预约
service = AppointmentService()
result = service.process_appointment(patient_data)

if result['success']:
    print(f"预约成功！预约ID: {result['appointment_id']}")
    print(f"医生: {result['doctor_info']['name']}")
    print(f"时间: {result['appointment_time']}")
else:
    print(f"预约失败: {result['message']}")

service.close()
```

## 核心功能

### 1. 自动创建患者病例

- 根据联系方式自动查重
- 生成唯一就诊卡号
- 保存完整的患者信息和病史

### 2. 智能匹配医生

- 根据科室查找可用医生
- 解析自然语言时间表达式（如"明天下午"）
- 匹配患者期望时间与医生空闲时间
- 考虑医生职称和患者偏好

### 3. 创建预约记录

- 在同一事务中完成患者和预约创建
- 自动确定病情严重等级
- 更新医生空闲状态

## 工作流程

```
一号智能体对话 
    ↓
获取患者 JSON 数据
    ↓
AppointmentService.process_appointment()
    ↓
├─ 创建/更新患者病例
├─ 查找可用医生
├─ 匹配最佳医生
└─ 创建预约记录
    ↓
返回预约结果
```

## API 参考

### `process_appointment(patient_json_data: Dict) -> Dict`

处理完整预约流程的主要接口。

**输入**: 一号智能体的患者数据字典

**输出**:
```python
{
    'success': bool,           # 是否成功
    'patient_id': int,         # 患者ID
    'appointment_id': int,     # 预约ID（成功时）
    'doctor_info': dict,       # 医生信息（成功时）
    'appointment_time': str,   # 预约时间（成功时）
    'message': str,            # 结果消息
}
```

## 支持的时间表达式

模块支持自然语言时间表达式：

- ✅ "明天上午" → 明天 09:00
- ✅ "后天下午" → 后天 14:00
- ✅ "11月15日" → 2025-11-15 09:00
- ✅ "下周" → 7天后
- ✅ "今天下午" → 今天 14:00

## 注意事项

1. **数据库连接**: 使用后调用 `service.close()` 关闭连接
2. **事务安全**: 患者和预约创建在同一事务中，失败自动回滚
3. **错误处理**: 所有错误都会返回在 `result` 字典中
4. **日志记录**: 关键操作会记录到日志

## 故障排除

### 连接失败

```
错误: Can't connect to MySQL server
解决: 
  1. 确认 MySQL 服务已启动
  2. 检查 db_config.py 中的配置
  3. 测试: mysql -u root -p20041118
```

### 找不到医生

```
错误: 未找到符合条件的可用医生
解决:
  1. 确认 doctor 表有数据
  2. 检查医生的 Available_Time 字段
  3. 尝试不指定期望时间
```

### 导入失败

```
错误: No module named 'pymysql'
解决: pip install pymysql
```
