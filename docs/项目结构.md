# 项目结构

本文档描述智能医疗咨询系统的代码组织、模块职责和主要调用链。项目采用分层架构组织业务代码，并使用 LangGraph 编排健康咨询、医疗报告、提醒管理、科研辅助、合规审查和产品推荐六类智能体。

## 1. 总体架构

```text
浏览器 / API 调用方
        │
        ▼
presentation          FastAPI 路由、请求与响应模型
        │
        ▼
agents                意图路由、状态图、智能体、提示词与工具
        │
        ├──────────► application       应用服务与仓储接口
        │                    │
        │                    ▼
        └──────────► infrastructure    数据库、外部 API、对象存储与仓储实现
                             │
                             ▼
                          domain       领域模型、枚举与业务异常
```

依赖原则：外层模块可以依赖内层抽象；`domain` 不依赖 Web、数据库或第三方服务，`application` 通过仓储接口隔离具体的数据来源，`infrastructure` 负责实现这些接口。

## 3. LangGraph 智能体结构

```text
START
  │
  ▼
router
  ├── health          健康咨询与分诊
  ├── report          医疗报告与处方查询
  ├── reminder        复诊、用药与预约提醒
  ├── research        科研检索与分析（医生）
  ├── compliance      医疗合规审查（医生）
  └── recommendation  医药产品推荐
          │
          ▼
    output_handler
          │
          ├── 继续处理 ──► router
          └── 完成 ──────► END
```

各 Agent 采用相同的拆分方式：

- `agents/graph/nodes/` 负责读取和更新图状态。
- `agents/prompts/` 负责模型角色、任务边界和输出约束。
- `agents/tools/` 负责查询业务数据或调用外部能力。
- `agents/graph/edges/routing.py` 负责选择下一个节点。

## 4. 一次请求的调用链

以通用对话接口为例：

```text
POST /api/chat
  → presentation/routers/chat_router.py
  → agents/graph_manager.py
  → 角色校验 + 输入安全检查
  → agents/graph/graph_builder.py 编译后的状态图
  → router_node 识别意图并选择 Agent
  → 对应 Agent node 调用 prompt 和 tools
  → response_node 整理输出
  → Checkpointer / PersistenceAdapter 保存状态与消息
  → Pydantic Schema 返回 HTTP 响应
```

同步请求使用 MySQL Checkpointer 保持会话状态；流式请求通过 SSE 持续返回内容。具体持久化行为由 `GraphManager` 和持久化适配器共同协调。

## 5. 新功能放置规则

新增代码时按职责选择目录：

| 需求 | 放置位置 |
| --- | --- |
| 新增 HTTP 接口 | `presentation/routers/`，模型放在 `presentation/schemas/` |
| 新增领域实体或业务枚举 | `domain/models/` 或 `domain/enums/` |
| 新增数据访问抽象 | `application/repositories/` |
| 接入数据库或第三方 API | `infrastructure/` |
| 新增 Agent | `agents/graph/nodes/`，并同步补充 `prompts/`、`tools/` 和图路由 |
| 新增跨模块安全或格式化能力 | `utils/`；仅被单个模块使用时优先放回该模块 |
| 数据库建表或迁移脚本 | `scripts/` |
| 架构或接口说明 | `docs/` |

新增 Agent 时，需要在 `graph_builder.py` 注册节点和边，在 `routing.py` 增加路由结果，并同步更新 Agent 类型、状态模型及对应接口文档。

## 6. 启动入口

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 20602 --reload
```

应用启动后：

- 首页：`http://127.0.0.1:20602/`
- Swagger：`http://127.0.0.1:20602/docs`
- 健康检查：`http://127.0.0.1:20602/health`
